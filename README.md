# Arithmetic & Datapath Library

A collection of synthesizable Verilog/SystemVerilog arithmetic IPs developed as part of an RTL Design Engineer portfolio.

## Modules

- ✓ Ripple Carry Adder (RCA)
- ✓ Carry Lookahead Adder (CLA)
- ✓ Carry Save Adder (CSA)
- ✓ Parameterized ALU (Coming Soon)
- ✓ MAC Unit (Coming Soon)

Each module includes:

- Synthesizable RTL
- Self-checking Testbench
- Vivado Synthesis Reports
- Waveforms
- Architecture Documentation
- Design Trade-off Analysis
