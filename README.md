# RTL Fundamentals

This folder contains a simple RTL design example for learning digital design concepts through a ripple-carry adder.

## Project Contents

- A parameterized ripple-carry adder implemented in Verilog
- A basic simulation testbench for functional verification
- A Vivado project workspace for opening and running the design

## Main Files

- Source design: [Ripple_Carry_Adder/Ripple_Carry_Adder.srcs/sources_1/new/RCA.v](Ripple_Carry_Adder/Ripple_Carry_Adder.srcs/sources_1/new/RCA.v)
- Testbench: [Ripple_Carry_Adder/Ripple_Carry_Adder.srcs/sim_1/new/RCA_tb_V.v](Ripple_Carry_Adder/Ripple_Carry_Adder.srcs/sim_1/new/RCA_tb_V.v)
- Vivado project: [Ripple_Carry_Adder/Ripple_Carry_Adder.xpr](Ripple_Carry_Adder/Ripple_Carry_Adder.xpr)

## Purpose

This project is intended for:
- understanding basic RTL structure
- practicing combinational design with full adders
- learning how to verify a simple digital circuit with a testbench
